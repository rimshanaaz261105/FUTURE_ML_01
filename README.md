# Sales & Demand Forecasting using Machine Learning

## Project Overview
This project predicts future sales using historical Walmart sales data.

The objective is to help businesses forecast demand and make better business decisions.

## Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn

## Features
- Data Cleaning
- Time-Based Feature Engineering
- Exploratory Data Analysis
- Machine Learning Forecasting
- Model Evaluation
- Sales Forecast Visualization

## Machine Learning Model
Random Forest Regressor

## Evaluation Metrics
- MAE
- MSE
- RMSE
- R² Score
